# Практическая работа № 9. Метод опорных векторов

**Вариант А**

В ноутбуке `svm_practice_A.ipynb` сравниваются линейное ядро и RBF на двумерном датасете `make_moons`. Признаки масштабируются через `StandardScaler`, обученный на тренировочной выборке. Графики границ решения, результаты и выводы находятся в ноутбуке.

## Запуск в VS Code

1. Откройте папку проекта в VS Code и установите расширения **Python** и **Jupyter** от Microsoft.
2. В терминале VS Code установите зависимости в выбранное окружение Python.

   ```powershell
   python -m pip install ipykernel matplotlib numpy scikit-learn
   ```

3. Откройте `svm_practice_A.ipynb`. Нажмите **Select Kernel** и выберите то же окружение Python.
4. Нажмите **Run All**, чтобы заново обучить модели и построить графики.

## Результаты

| Ядро | C | Точность на тесте | Опорные векторы |
| --- | ---: | ---: | ---: |
| Linear | 1 | 85,33% | 73 |
| RBF | 1 | 89,33% | 72 |
| RBF | 0,1 | 88,00% | 126 |

RBF при `C=1` лучше разделяет изогнутые классы. При `C=0.1` ошибки на обучении штрафуются слабее, граница становится менее изогнутой, а точность на тесте снижается до 88,00%.

Шаблон задания отсутствовал в папке проекта. Для эксперимента выбраны предложенный в задании датасет `make_moons` и значение `C=0.1` для повторного обучения RBF.
